# Interfaz del inventario

La aplicación React se comunica únicamente con el API Gateway.

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

El valor local predeterminado de `VITE_API_URL` es `http://localhost:8080`. Consulta el [README del proyecto](../README.md) para configurar MySQL y arrancar los microservicios.
